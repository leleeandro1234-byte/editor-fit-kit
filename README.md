# Editor Fit com IA

Kit para nutricionistas e personal trainers editarem vídeos fit com o Claude Code.

## O que faz
1. Fornece calorias de comparação entre alimentos
2. Divisão A/B das falas (lado a lado)
3. Infográficos e simulações de exercício
4. Legendas automáticas, cortes e zoom
5. Instruções de gravação e sugestões de melhoria

## Instalar (3 passos)
1. Instale o Claude Code (claude.com/claude-code)
2. Baixe este repositório (git clone ou Download ZIP) e abra a pasta no terminal
3. Rode `./install.sh`

## Usar
Abra o Claude Code e diga: `editor fit, quero um vídeo sobre <seu tema>`.

## Aulas em vídeo
Veja `aulas/README.md`. Quatro aulas curtas: instalar o Claude Code, instalar o kit, configurar chave (opcional) e primeiro vídeo.

## Estrutura
- `skills/` skills do Claude (editor-fit, remotion-ads)
- `template/` projeto Remotion base
- `curso/` texto de apoio
- `aulas/` aulas em vídeo (roteiros + código)
- `exemplos/` vídeos de exemplo
